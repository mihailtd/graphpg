- **Subscriptions (live queries)** (#25, #26, #27, [guide](docs/subscriptions.md)), opt-in with `subscriptions.enabled`: a `Subscription` type with the `Query` type's root fields, whose result is sent again whenever it changes. Every `subscriptions.interval` (1 s) each instance runs its subscriptions again, batched: subscriptions of one compiled query and the same claims are one statement (the query `LATERAL`-joined to their parameters, returning only results whose hash changed), every user's claims applied and reset in their own savepoint, and claims left out of the grouping when the query reads only tables without Row-Level Security. Runs read from replicas when there are any. Transports: WebSocket (`graphql-transport-ws`, as Apollo Router uses with subgraphs), GraphQL over SSE and multipart HTTP; GraphiQL runs subscriptions over SSE. The token is checked when subscribing and the subscription ends when it expires. Limits per instance and per client; metrics `graphpg_subscription_active`, `graphpg_subscription_round_duration_seconds`, `graphpg_subscription_results_total`. Nothing is installed in the database.
