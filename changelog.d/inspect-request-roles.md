- **Fixed: the documented authentication setup exposed no tables** (#223). With a `NOINHERIT` login role holding no privileges, the schema was built from the login role's privileges, so it had no tables. Relations and functions a request role (`auth.roles.authenticated` or `auth.roles.anonymous`) has a privilege on are now exposed, and `rbac.enabled` without `rbac.role` prunes as `auth.roles.authenticated` when authentication is on.
