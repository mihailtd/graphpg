- **Fixed: a join made writable with `DO INSTEAD` rules could get its base table's key.** PostgreSQL counts a view with `DO INSTEAD` rules on updates and deletes as updatable, so such a view (a join whose rows repeat) passed the check for simple views. Views with these rules no longer get a detected key; declare one with `@primaryKey` or `primary_key` if their rows are unique. A new [Views](docs/views.md) page describes what views get, their keys, writes, relations, security and the cases to watch.
