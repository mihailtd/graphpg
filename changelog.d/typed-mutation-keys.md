- **Breaking: updates and deletes take the row's key typed as queries take it**: `updatePost(id: Int!)`, `updateUser(id: UUID!)` (was `id: ID!` for every table with a single-column key). Global IDs have their own fields: `update<Type>ByNodeId(nodeId: ID!)` and `delete<Type>ByNodeId(nodeId: ID!)`, which refuse the ID of another type (the global ID used to be decoded whatever its type).
