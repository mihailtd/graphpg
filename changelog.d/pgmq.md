- **pgmq integration** (#172): the queues named in `extensions.pgmq.queues` (or `"*"`) are served as API: `send<Queue>Message(s)`, `read<Queue>Messages` (visibility timeout), `pop`, `delete` / `archive` (acknowledge), `set<Queue>MessagesVisibility` and the `<queue>QueueMetrics` query, over GraphQL and `/rest/rpc/…`, with GRANTs, limits and errors as for any function. Built on functions with fixed arguments: pgmq's own functions, the queue bound, no special code path.
