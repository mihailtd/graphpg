- Fixed: OpenAPI `default`s were the SQL of the column default, as strings (`"false"`, `"5"`, `"'active'::text"`, `"uuidv7()"`), in row and request schemas (#213). A constant default is now a JSON value of the property's type (`false`, `5`, `"active"`; a 64-bit or decimal one as a string, an enum's as its API name, a `json` one as the value), and a default PostgreSQL computes (`now()`, `uuidv7()`, `nextval(…)`, any expression) has no `default`: the database still fills it in. Nothing is evaluated. Re-export pinned OpenAPI documents.
